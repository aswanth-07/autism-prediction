# Model card

## Overview

This project compares five traditional supervised architectures—Logistic Regression, RBF Support
Vector Classification, Random Forest, Extremely Randomized Trees, and a custom out-of-fold hybrid
stack with an MLP meta-learner—behind the same leakage-safe preprocessing contract. The selected
release model and exact metrics are generated together by `python -m asd_screening.training` and
stored in `models/` and `reports/`.

## Intended use

The model is an educational demonstration of tabular classification, nested cross-validation,
threshold selection, artifact versioning, and inference validation. It is not a medical device, a
diagnosis, a clinical screening instrument, or a replacement for a qualified professional.

## Evaluation protocol

1. Restrict the supplied data to ages 18–100.
2. Reserve a stratified 20% holdout with random seed 42.
3. Tune and compare model families using nested stratified cross-validation on training rows only.
4. Select the model family by mean outer-fold positive-class F1, with ROC-AUC as a tie-breaker.
5. Select a decision threshold by maximizing F1 on five-fold out-of-fold training probabilities.
6. Fit once on all training rows and evaluate once on the untouched holdout.

The report includes F1, precision, recall, balanced accuracy, ROC-AUC, average precision, Brier score,
confusion matrix, and bootstrap uncertainty intervals. See `reports/metrics.json` for machine-readable
values and `reports/figures/` for plots.

## Release metrics

The 5×4 nested protocol selected **Extremely Randomized Trees** with nested F1 **0.695 ± 0.066**.
On the untouched 116-row holdout at the training-derived threshold of 0.480:

| Metric | Value |
|---|---:|
| F1 | 0.679 (95% bootstrap CI 0.511–0.816) |
| Recall | 0.720 |
| Precision | 0.643 |
| Balanced accuracy | 0.805 |
| ROC-AUC | 0.924 (95% bootstrap CI 0.866–0.969) |
| Average precision | 0.791 |
| Brier score | 0.097 |

The confusion matrix is `[[81, 10], [7, 18]]` in `[[TN, FP], [FN, TP]]` order. These values describe
one small supplied dataset and must not be generalized to clinical performance.

### Hybrid ensemble result

The historical hybrid notebook reported holdout F1 0.676 for target-encoded data. Its MLP training
features were generated by base learners fitted on those same training rows, so they were not actually
out of fold. The corrected architecture uses cross-fitted Random Forest, SVC, and AdaBoost
probabilities, fold-local feature selection, and a compact MLP. Under the shared nested protocol it
reached F1 **0.629 ± 0.072**, below Extra Trees at **0.695 ± 0.066**. The model is retained as a
documented experiment, not promoted as the release winner.

## Important limitations

- Only 577 adult rows are available, so the holdout contains few positive cases and intervals are wide.
- Dataset provenance and collection methodology are absent from the repository.
- Demographic categories are imbalanced and incomplete; fairness is not established.
- The model score is not guaranteed to be calibrated and is not an individual clinical probability.
- The interface accepts source feature values, not an independently validated questionnaire.
- Performance on this supplied dataset does not establish external or clinical validity.

## Reproducibility

The artifact stores the pipeline, decision threshold, project and scikit-learn versions, selected
model label, feature schema, category options, intended use, UTC generation time, and SHA-256 hash of
the raw CSV. CI runs linting, static type checks, and tests against the serialized release artifact.
The web exporter additionally serializes the exact selected forest into a static format and verifies
its scores against scikit-learn to less than `1e-12` absolute error.
